# uni-halo-qh

基于 [Halo 2.x](https://halo.run/) 开源博客系统的微信小程序项目的本地定制工作区，包含两个子项目：

- `uni-halo`：uni-app（Vue 2）编写的小程序前端（v2.0.10），基于 Halo 2.x API，支持文章/分类/图库/瞬间/恋爱日记/投票/积分等功能，可编译为微信小程序或 App。
- `plugin-uni-halo`：配套的 Halo 配置插件（Java 17 / Gradle），为小程序提供后台配置和扩展能力，包括微信登录用户体系、积分、用户活动、点赞追踪、评论代理、Halo 账号绑定等。

两个子项目在本地各自维护独立的 git 历史（原远端：Gitee 与 GitHub），本仓库是工作区的整体快照（不含构建产物）。
