📰 AI 日报 · 生成与发布管理

每天定时抓取技术博客 → AI 精选成稿 → 通过 Halo 官方接口发布文章。Token 仅保存在本机浏览器。

生成一次约需 1-3 分钟，正文较长时发布确认还要更久；触发后页面会自动刷新，不用手动点。Token 需要是超级管理员令牌。注意：「发布」只会发出这一期在生成时就已经固化的文章（逐篇模式下为 N 篇独立文章）；早期生成的记录里没有逐篇内容，只能整体补发一篇日报。若某一期是「只生成不发布」，点「发布」即可把它备好的文章写入 Halo；已建过稿的篇目只会重新触发发布，不会重复建稿。

🩺 发布环境自检结果

自检只读取信息、不会发布任何内容；不通过的项按提示改完再点「发布」。

🏷 日报分类（AI 只能从这份清单里选）

清单在「插件设置 - AI 日报 - 日报分类」里维护：留空 = 用内置六类（与升级前完全一致）； 「落库方式」决定分类不存在时是自动创建、只复用已有、还是按映射指定。 reuse / map 模式下匹配不上的行会被静默跳过（不会自动创建分类），所以这类行在下面标红列出。 清理只删除带 uni.uhalo.pro/auto-generated 标签、且没有任何文章引用的分类。

🔌 大模型通道（顺序即优先级）

第一条调用失败会自动跳到下一条；关掉的通道不参与调用。清单留空时沿用旧的主 / 兜底通道 （也就是「插件设置 → AI 日报」里那组兼容字段）；点「导入现有通道」可以把它们搬进清单。 「测试」只发一次 8 token 的极小请求，会真实产生极少量费用；API Key 一律以掩码显示，留空即表示不修改。
用途留空 = 什么活都接；某任务的通道全不可用时（例如只勾了「评分」的便宜通道被关掉）会回退到全部可用通道， 并在上方标出「回退」，不会让整轮日报失败。

📣 消息推送（微信订阅消息）

开关与模板 ID 在「插件设置 → 消息推送」里配置。普通类目只能用一次性订阅：用户点一次授权，只能发一条——授权额度存在插件里（微信不提供查询），所以「额度用尽（43101）」多说明用户需要再点一次小程序里的「开启更新提醒」。
失败的完整记录在 Halo 控制台的扩展列表里搜 PushRecord 也能看到。
