📮 微信公众号 · 文章生成与推送

按方向（默认 AI 发展 / AI 安全 / Vibe Coding）每天生成精选文章并推送到公众号。 主路径：把文章推成草稿（能用则用），或在这里「复制正文」直接粘进公众号编辑器发布——复制路径不调用微信接口，任何账号类型都可用。 Token 仅保存在本机浏览器。配置项在：插件设置 → 微信公众号。

生成约需 1-3 分钟（抓取 92 个源 + AI 评分 + 逐方向成稿），推送含图片上传与发布确认，触发后页面会自动刷新状态。 「深度自检」会真实创建一条测试草稿并立即删除，用来确认草稿箱接口对当前账号是否可用（个人订阅号能否用草稿箱，官方无明文保障）。

① 接入状态

请先输入 Personal Token 并点击「刷新」

🩺 自检结果

自检逐项真实调用微信接口。不通过的项按提示处理（多数是 IP 白名单或账号权限）。

② 公众号稿件

暂无稿件：点上方「立即生成」产出今天的第一批

状态含义：已生成（待推送）→ 已进草稿箱 → 已发布 / 已群发；空稿表示该方向本期没有候选文章。 「复制正文」会先把正文图片换成微信图床地址（可用时），再复制富文本，直接粘进公众号编辑器即可；摘要在标题下方单独复制（公众号列表里显示的就是它）。

③ 历史 AI 日报补推

点「刷新历史期次」查看往期日报

补推用的是那一期当时固化下来的内容（不重新抓取、不花 AI）：整期合并输出一篇图文，逐篇则每篇文章各成一稿。 生成后同样可以预览、复制或推送草稿箱。
