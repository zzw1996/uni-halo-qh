# Halo 小程序 UI 重新设计

基于 `uni-halo` 现有页面与组件设计的六张概念效果图，使用内置 ImageGen 生成。图片中的文章、用户与统计数字均为示例，不代表线上数据。概念图与前端适配记录均已保存；适配进度与验证范围见 implementation.md。

## 视觉方向

暖白纸面与深青绿，保留博客的阅读气质，并统一社区与个人中心的视觉语言。减少大面积渐变、杂色图标和重阴影，让文章标题、封面与主要动作成为视觉重点。

| 项目 | 建议值 |
| --- | --- |
| 页面背景 | `#F6F7F2` |
| 卡片背景 | `#FFFFFF` |
| 品牌 / 主要动作 | `#176B5B` |
| 主文字 | `#172C27` |
| 次文字 | `#65736D` |
| 分隔线 | `#E3E8E2` |
| 品牌浅底 | `#E7F0E9` |
| 页面左右留白 | 20 px / 40 rpx |
| 常规卡片圆角 | 16 px / 32 rpx |
| 正文字号 | 15–17 px，阅读正文行高约 1.75 |
| 页面参考尺寸 | 390 × 844 逻辑像素 |

## 后续落地约束

- 保留五个主导航：首页、发现、瞬间、榜单、我的。文章详情使用返回导航与互动栏。
- 顶部给微信原生胶囊预留位置；底部适配安全区域，悬浮发布按钮避开导航。
- AI、视频号、小店、付费权益与投稿入口仍由当前后台配置和权限决定是否显示。
- 订阅额度、暂停状态、登录门槛、付费墙与积分兑换沿用已有逻辑；相关弹窗与空状态需在实现阶段补齐。
- 推荐在 `uni.scss` 维护 SCSS 设计变量，遵循当前项目的小程序样式约束。
- 图片用于视觉评审；生成图中的文字、图标、尺寸和数值需在开发时使用真实组件与数据重建。

各页最终提示词随对应图片保存在此目录。
