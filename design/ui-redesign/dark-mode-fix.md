# 暗色模式修复

本次修复覆盖页面、组件、文章正文以及原生底栏。

- 皮肤生成器识别 #fff 等三位色值，白卡片、底栏、安全区和浮层转换为深色。
- 皮肤选择器同时匹配当前页面根节点及后代；保留 data-v 作用域，避免 .head/.content 等同名样式串页。
- 按最终声明生成覆盖，后续 transparent/none 撤销旧背景和阴影；忽略已生成的皮肤规则，避免重复累积。
- 暗色链接保留亮色；实心按钮使用深蓝底，使白色按钮文案清晰。
- Markdown 通过响应式主题配置更新内联颜色，mp-html 在主题变化时重新解析已打开的正文。
- 文章后台标签色在深色阅读页统一为深底亮字。
- 原生底栏增加深色字体图标资源，切回浅色恢复原图标；自绘底栏通过皮肤覆盖更新。

验证：生成器回归、Vue 响应式主题切换、切回浅色、跟随系统、保留原皮肤和原生图标切换检查通过。微信正式包编译和体积检查通过。本轮没有可用的界面控制工具，未取得修复后的微信模拟器或真机截图；先前浅色截图不作为本次暗色视觉验收证据。

源码回归命令：`node uni-halo/tools/test-skin-generator.cjs`。
重新生成时先编译最新源码，再运行 `node uni-halo/tools/gen-skins.cjs <干净的微信编译目录>`，最后重新编译以纳入生成的皮肤规则。
