# 图标与视觉精修

采用 Lucide 1.56.0 官方图标，ISC 许可保存在 `uni-halo/static/ui-icons/LICENSE.txt`。只打包选用的 PNG，没有增加小程序运行时依赖。

本轮已落地：
- 个人中心服务网格：统一圆角线条，青绿、蓝、琥珀、珊瑚四组柔和色板；历史、订单、投稿、客服等使用不同语义图形。
- 身份与权益入口：皇冠与礼物图标，独立淡色底；设置和任务入口同步图标语言。
- 首页：AI 星芒图标、视频播放标识，运营卡片减小内边距与描述行数。
- 自绘导航：统一线条图标与柔和选中背景；原生导航同步相同图标。首页、发现、图库、榜单、我的与小店均配齐浅/暗、普通/选中资源。
- 保持服务路由、登录约束、后台功能开关与客服/反馈行为。

`verification/icon-system.png` 展示实际生成的图标资源及浅暗配色，是图标规范展示，不是运行中的页面截图。

验证：微信正式包编译通过，主包 1826 KB（小于 2048 KB）；74 个图标尺寸/非空检查、可选导航资源、服务属性保留检查与暗色回归通过。当前无界面控制工具，尚未取得新版页面截图，完整视觉验收保持待验证。

重建图标：`python3 uni-halo/tools/generate-ui-icons.py <lucide-static 包目录>`（需要 Pillow）。页面样式修改后重新编译、运行皮肤生成器、再编译，确保暗色样式跟随最新作用域。
